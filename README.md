## 👋 This is the repo for my personal website whatisakatie.me


- 🐍 Flask for the backend 
- 🖋️ Poetry for depdencies
- 💻 Render for deployment
- 🖌️ Custom CSS


💡 The `terminal` view is using a few public APIs to pull in a random fact, cat fact, etc depending on what you pick! `help` will give you a list of commands. 

🎨 I love all things bright so I really wanted to take my sight to the next level with a 90s Hackers the movie vibe.
